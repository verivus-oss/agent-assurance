# It's Just Business (IJB)

A framework for projecting business reality into spatial representations without abstraction.

## Core Principle

**The visualization does not explain the business.**
**It lets you stand inside the description and look around.**

This is not a modeling tool. This is not a diagramming system. This is a projection framework that takes factual descriptions and renders them as navigable space.

## The Six Primitives

All business reality that IJB projects — the observable facts about what exists, how it moves, and what was witnessed — can be described using six primitives:

1. **Things** - Objects that exist
2. **Scopes** - Contexts in which things exist
3. **Paths** - Connections along which things move
4. **Observed** - Facts that were witnessed
5. **Constraints** - Limits that restrict movement
6. **Time** - The dimension that orders everything

These primitives are never visual artifacts themselves. They are facts. Visualization only answers: "How do we arrange these facts so a human can perceive relationships?"

## What This Prevents

- Executive diagrams lying by simplification
- Technical diagrams being dismissed as too detailed
- Different roles seeing different "truths"
- Slides becoming the source of record

Everyone stands in the same description, just at different distances.

## What Visualization Is Allowed To Do

- Hide detail by distance
- Reveal detail by focus
- Emphasize relationships
- Expose delay and blockage
- Make absence visible

## What Visualization Is Forbidden To Do

- Invent concepts
- Explain intent
- Suggest causality
- Imply correctness
- Replace the description

## Reality Check

If someone can point at the visualization, ask "what is that?", and the answer is one of the six primitives, then it is working.

If the answer is "strategy", "culture", "alignment", or "risk posture", then it has already failed.
