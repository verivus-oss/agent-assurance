This worked example models a single SkillOpt optimisation run from "SkillOpt: Executive Strategy for Self-Evolving Agent Skills" (arXiv:2605.23904) as conformant DAG-TOML.
It captures the SpreadsheetBench/GPT-5.5 case where the held-out test score rose from 40.4 to 78.9 after four accepted edits, with closure roots computed as real digests over the skill bytes.
