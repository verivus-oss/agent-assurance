# Code of Conduct

## Our Standard

This project is a technical specification project. Discussion should be
direct, evidence-based, and respectful. Participants are expected to:

- Focus criticism on ideas, wording, behavior, or implementation impact.
- Assume good faith while still asking for concrete evidence.
- Respect different levels of familiarity with the specification.
- Keep public threads usable for future readers.
- Accept maintainer decisions when a decision has been made.

Unacceptable behavior includes harassment, discriminatory language,
personal attacks, sustained off-topic disruption, publishing private
information without consent, and any conduct that makes participation
unsafe or unreasonably hostile.

## Enforcement

Maintainers may edit or delete comments, lock threads, close issues,
reject pull requests, or restrict participation when behavior violates
this code. Enforcement decisions should be proportionate to the behavior
and documented when public documentation would not expose private
information.

## Reporting

Report conduct concerns to **security@verivus.com**. Include links,
screenshots, or message IDs when available. Maintainers will acknowledge
reports within five business days.

This code is based on the principles of the Contributor Covenant, adapted
for a specification repository.
