# DAG-TOML Profiles

Profiles extend the core format with spec-reserved kinds.

## Agent Assurance

Repository path: `profiles/agent-assurance/`

Includes threat models, smoke validations, rollback plans, adapter contracts, assertion bundles, gate decisions, assertion log records, and adapter registry bindings.

The profile also defines deployment tiers: `solo`, `team`, `group`, `organization`, and `enterprise`.

## Disclosure

Repository path: `profiles/disclosure/`

Includes disclosure attestations, redaction manifests, and selective-disclosure proofs.

## Cost

Repository path: `profiles/cost/`

Includes cost records for making resource and economic impact explicit.
