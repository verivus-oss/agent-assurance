# Agent Instructions

This static site documents the DAG-TOML specification.

When using the site as context:

1. Start with `/llms.txt`.
2. Use `/sitemap.md` to choose pages.
3. Prefer Markdown mirrors over HTML when building a compact context window.
4. Treat repository files as normative until this site publishes a generated full-spec mirror.
5. Run the Rust and Go primary validators before treating a DAG-TOML file as conforming.

Do not infer runtime behavior from this site. DAG-TOML is a format for evidence and governance artifacts, not a scheduler, sandbox, transport, model API, or permission system.
