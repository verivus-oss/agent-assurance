# DAG-TOML

DAG-TOML is a public draft specification for declarative policy, workflow, traceability, evidence, closure roots, and review gates in agent-driven software development.

Canonical site: https://agent-assurance.dev/

Repository: https://github.com/verivus-oss/agent-assurance

Release: https://github.com/verivus-oss/agent-assurance/releases/tag/v0.1.0

## Position

DAG-TOML is the evidence and governance layer for agentic software work. It is not a runtime, model API, message transport, sandbox, package registry, or permission system.

Use it to describe:

- planned work and dependency order
- evidence expectations
- traceability from requirements to code, tests, and outputs
- closure-root provenance
- readiness for human review
- disclosure, redaction, and cost artifacts
